# `contracts/`

`contracts/` holds the spec-driven sources of truth for the D² platform. Each contract is consumed by a .NET Roslyn source-gen and/or a `tools/ts-codegen` emitter and/or the TypeSpec emitter fleet; generated output is committed and byte-gated. For the codegen pattern (generator anatomy, `<AdditionalFiles>` wiring, diagnostic-ID convention) see [docs/SRC_GEN.md](../docs/SRC_GEN.md).

The **Consumed by** column links straight to each consumer's README (or the consumer source where it has no README of its own); each contract's own stub links back in the other direction.
