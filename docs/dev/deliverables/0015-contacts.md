## Locked design — VALUE OBJECT BREAKDOWN

### Field-length constants (codegen-emitted; the `Create` gate)
255: FIRST/MIDDLE/LAST/PREFERRED_NAME_MAX, COMPANY_NAME_MAX, JOB_TITLE_MAX, DEPARTMENT_MAX, STREET_LINE_MAX, CITY_MAX. 2048: COMPANY_WEBSITE_MAX. 64: AFFIX_CUSTOM_MAX. 16: POSTAL_CODE_MAX. 254: EMAIL_MAX. 32: PHONE_E164_MAX. 7/15: PHONE_MIN_DIGITS / PHONE_MAX_DIGITS.

### Taxonomy enums (codegen-emitted; closed lists, string-wire, `[JsonConverter(JsonStringEnumConverter)]`, byte-backed)
- `NamePrefix` (17): Mr, Ms, Miss, Mrs, Mx, Dr, Prof, Sir, Lady, Lord, RtHon, Rev, Fr, Pr, Sr, Elder, Other.
- `NameSuffix` (13): Jr, Sr, I, II, III, IV, V, VI, VII, VIII, IX, X, Other.
- `BiologicalSex` (4): Male, Female, Intersex, Unspecified. (No `Other`.)

### Value objects (each `Create(...) → D2Result<T>`; pure-static dumb floor; smart validator = optional `Create` param)
- **Personal** — FirstName(req, ≤255), Middle/Last/Preferred(≤255 each); `HashId` = `"v1."+SHA256(NormalizeForHash(First)|Middle|Last)` (excludes Preferred). `[RedactData(PersonalInformation)]` on names; HashId visible. HashId IS in the anonymize default-bundle. Fails: FIRST_NAME_REQUIRED, *_TOO_LONG.
- **NameAffixes** — Prefix(NamePrefix?), PrefixCustom(string?, ≤64), Suffix(NameSuffix?), SuffixCustom(string?, ≤64). Custom required iff enum==Other, forbidden otherwise. Reject all-null. `[RedactData]` on customs. Fails: PREFIX/SUFFIX_CUSTOM_REQUIRED, PREFIX/SUFFIX_CUSTOM_NOT_ALLOWED, AFFIXES_EMPTY_RECORD.
- **Demographics** — DateOfBirth(DateOnly?, not future, not >150y), BiologicalSex(BiologicalSex?). Reject all-null. `[RedactData]` both. Fails: DOB_FUTURE, DOB_TOO_OLD, DEMOGRAPHICS_EMPTY_RECORD.
- **Professional** — CompanyName(req, ≤255), JobTitle/Department(≤255), CompanyWebsite(Uri?, absolute http/https, raw ≤2048). NO HashId. `[RedactData]` on Company/JobTitle/Dept; website visible. Fails: COMPANY_NAME_REQUIRED, *_TOO_LONG, WEBSITE_INVALID.
- **EmailAddress** — thin Value(req). `Create(value, IEmailValidator? = null)`. Floor: trim+lower+non-empty+contains '@'+≤254. With validator: bubble D2Result. `[RedactData]` Value.
- **PhoneNumber** — thin Value(req). `Create(value, IPhoneValidator? = null, CountryCode? region = null)`. Floor: digits 7–15, ≤32. With validator: bubble E.164. `[RedactData]` Value.
- **Address** — REUSE Location `StreetAddress`/`AdminLocation` (no new VO). Caps added by Location retrofit.
